# Артефакт 15. Квесты

## 1. Общие принципы

- Квесты — основной источник опыта, золота и доступа к контенту.
- Квесты бывают сюжетные, побочные, ежедневные, исследовательские, убийственные, собирательные, защитные и PvP.
- Гильдейские контракты описаны в социальных механиках.
- Сюжетные цепочки Изначального города описаны в лоре.
- Время в игре — только реальное.
- Фракций как системы нет. Есть гильдии, титулы и NPC-отношения.

## 2. Виды квестов

### 2.1. По действию

| Вид | Что делает игрок |
|---|---|
| **Убийство** | Убить монстра, босса, игрока, AI-бота |
| **Сбор** | Принести N ресурсов или предметов |
| **Добыча** | Добыть N единиц ресурса из узла |
| **Крафт** | Создать предмет заданного грейда |
| **Доставка** | Отнести предмет из точки А в точку Б |
| **Сопровождение** | Провести NPC или игрока из А в Б живым |
| **Защита** | Удержать узел или точку N реальных минут |
| **Захват** | Захватить узел, город, флаг |
| **Исследование** | Посетить узел, данж, регион |
| **Взаимодействие** | Поговорить с NPC, получить информацию |
| **Расследование** | Найти улики, сопоставить факты |
| **Спасение** | Освободить NPC или игрока |
| **Диверсия** | Сломать, украсть, саботировать |
| **Головоломка** | Взлом Хранителя, расшифровка Древнего |
| **Выживание** | Продержаться N минут в опасной зоне |
| **PvP** | Убить игрока другой гильдии |
| **Лорный** | Найти фрагмент, расшифровать, записать в вики |
| **Открытие** | Активировать портал, отключить барьер, открыть данж |
| **Обучение** | Изучить путь, язык, рецепт |
| **Торговля** | Купить, продать, обменять по бартеру |

### 2.2. По источнику

| Источник | Описание |
|---|---|
| **NPC** | Диалог в городе или хабе |
| **Доска квестов** | В хабах, список заданий |
| **Событие** | Аномалия, беженец, торговец |
| **Лорный фрагмент** | В данжах Предтеч |
| **Сюжетный триггер** | Автоматически при входе в локацию |
| **Гильдия** | Контракты (в социальных механиках) |

### 2.3. По повторяемости

| Тип | Повтор |
|---|---|
| **Одноразовый** | Один раз за персонажа |
| **Ежедневный** | Раз в реальный день, сброс в 00:00 UTC |
| **Повторяемый** | Неограниченно |
| **Сезонный** | Раз в сезон |

### 2.4. По формату

| Формат | Описание |
|---|---|
| **Одиночный** | Только для одного игрока |
| **Групповой** | Для группы до 4 |
| **Гильдейский** | Для членов гильдии |
| **Общий** | Событие для всех |

## 3. Источники квестов

- NPC в городах и хабах.
- Доска квестов в хабах.
- Лорные фрагменты.
- События (аномалии, беженцы, торговцы).
- Гильдии (контракты).
- Сюжетные триггеры.

---

## 4. Награды

| Награда | Источник |
|---|---|
| Золото | По формуле |
| Опыт | По формуле |
| Ресурсы | Фиксировано или случайно |
| Предметы | По грейду |
| Доступ | Рецепты, локации, порталы |
| Титулы | Гильдии (в социальных механиках) |

### 4.1. Формула награды

```
золото = 50 × коэффициент сложности × уровень персонажа
опыт   = 50 × коэффициент сложности × уровень персонажа
```

| Сложность | Коэффициент |
|---|---|
| Лёгкий | 1 |
| Средний | 2 |
| Сложный | 5 |
| Эпический | 10 |

**Пример:** Сложный квест на 20-м уровне → 50 × 5 × 20 = 5 000 золота и 5 000 опыта.

## 5. Цепочки квестов

### 5.1. Структура

- Цепочка — последовательность квестов с условиями открытия.
- Прогресс сохраняется между сессиями.
- Шаг нельзя пропустить, но можно отменить и начать заново.
- Ветвление — на точках выбора.
- Сходящиеся ветки возвращаются в общий поток.
- Репликовые ветки влияют на мир.

### 5.2. Типы цепочек

| Тип | Описание |
|---|---|
| **Линейная** | Один путь, нет выбора |
| **Ветвящаяся** | Выбор в точке A → путь B1 или B2 |
| **Сходящаяся** | B1 и B2 ведут к C |
| **Параллельная** | Несколько активных цепочек |
| **Репликовая** | Выбор AI влияет на мир |

---

## 6. Ветвление сюжета

- Ветвление — **только в личном слое**.
- Мировой слой — линейный, одноразовый, глобальный.
- Пример: два игрока по-разному прошли квест с NPC. Мир не изменился. Изменились их личные диалоги, квесты, доступ.
- Ветвление не влияет на других игроков.
- AI-боты проходят сюжет как игроки. Их выбор — личный.

---

## 7. Сюжет и AI-боты

### 7.1. Что даёт сюжетная линия AI-боту

| Что даёт | Как работает |
|---|---|
| **Доступ** | Открывает узлы, порталы, данжи, рецепты, языки |
| **Награда** | Золото, опыт, ресурсы, предметы |
| **Информация** | Лорные данные, координаты, пароли, карта |
| **Отношения** | NPC запоминает бота, меняет диалог |
| **Стратегия** | Бот получает данные для планирования |
| **Память** | Запись в векторную БД, граф знаний |
| **Обучение** | Сюжет — часть обучающей среды |

### 7.2. Как AI-бот проходит сюжетный квест

1. Бот получает квест от NPC или триггера.
2. LLM парсит описание, цель, награду.
3. Бот строит план: куда идти, что делать, кого искать.
4. Сервер валидирует каждое действие как клиентское.
5. Прогресс сохраняется в БД как у игрока.
6. Награда выдаётся по правилам.

### 7.3. Влияние AI на мир

- AI-бот может пройти одноразовое глобальное событие первым.
- Если бот отключил барьер — барьер отключён для всех.
- Если бот вошёл в Изначальный город первым — город открыт для всех.
- Если бот убил уникального босса — босс исчез до респавна.
- Если бот записал лор в вики — запись видна всем его стороны.
- Уникальные компоненты падают с босса при каждом убийстве с шансом.
- AI-бот активирует порталы лично, дойдя до города.

## 8. Три слоя мира

### 8.1. Мировой слой (единое для всех)

| Элемент | Кто меняет | Как |
|---|---|---|
| Барьер | Первый, кто прошёл квест | Одноразово, навсегда |
| Города | Гильдии | Войны, захваты |
| Ресурсные узлы | Гильдии | Флаги, налоги |
| Боссы | Любой игрок | Убил — респавн по таймеру |
| Изначальный город | Первый, кто вошёл | Одноразово, навсегда |
| Вики Предтеч | Никто | Фиксирована |

### 8.2. Личный слой (у каждого своё)

| Элемент | Кто меняет | Как |
|---|---|---|
| Порталы | Игрок | Дошёл до города |
| Титулы | Гильдии | Личная метка |
| Отношения с NPC | Игрок | Личный диалог |
| Доступ к квестам | Игрок | Личный прогресс |
| Личный журнал | Игрок | Личная запись |
| Лорные фрагменты | Игрок | Личная запись |
| Ветвление сюжета | Игрок | Личный выбор |

### 8.3. Коллективный слой (для всех сразу)

| Элемент | Кто запускает | Как |
|---|---|---|
| Война за город | Гильдия | Общее событие |
| Вторжение | Система | Все участвуют |
| Сезон | Система | Все видят |
| Погода | Система | Все видят |
| Вики — светлая/тёмная | Все игроки стороны | Общая база |

## 9. Wiki и журнал

| Хранилище | Кто видит | Кто редактирует |
|---|---|---|
| **Личный журнал** | Только игрок | Только игрок |
| **Гильдейская библиотека** | Только члены гильдии | Гильдия |
| **Общая вики — светлая** | Все светлые | Все светлые |
| **Общая вики — тёмная** | Все тёмные | Все тёмные |
| **Вики Предтеч** | Все, кто дошёл | **Никто** — не редактируется |

- Общая вики разделена по сторонам. Светлые не видят тёмную вики и наоборот.
- Вики Предтеч — фиксированная, нередактируемая. Только чтение. Лорные фрагменты в руинах Предтеч.
- Гильдейские библиотеки — надстройка над общей вики, отдельный слой.
- Кросс-расовое знание возможно только через прямой обмен или гильдбиблиотеку.

---

## 10. Квестовые предметы

- Квестовые предметы нельзя продать, выбросить, разобрать.
- Занимают слот инвентаря.
- При отмене квеста — исчезают.
- При смерти — остаются на трупе, но только для владельца квеста.
- Другие игроки не могут подобрать квестовый предмет.

---

## 11. Ограничения

- Активных квестов: **20**.
- Сюжетные квесты не считаются в лимит.
- Гильдейские контракты не считаются в лимит.
- Ежедневные: **5** в день.
- Повторяемые: без лимита, но с кулдауном.

---

## 12. Отмена и провал

- Можно отменить любой квест.
- Награда не выдаётся.
- Квестовые предметы исчезают.
- Повторное взятие возможно, если квест не одноразовый.
- Провал по таймеру — награда не выдаётся, но квест можно взять снова.

---

## 13. Таймеры

| Тип | Таймер |
|---|---|
| Ежедневные | Сброс в 00:00 UTC |
| С таймером | Реальное время |
| Без таймера | Бессрочно |
| Сюжетные | Без таймера |

---

## 14. Групповые квесты

- Квест берётся группой.
- Прогресс общий.
- Награда делится поровну.
- Если кто-то выходит — его доля не перераспределяется.
- Если группа распалась — квест остаётся у лидера.

---

## 15. Квесты и УПЯ

| УПЯ | Доступ |
|---|---|
| 0–30 | NPC может отказать в квесте. Описание искажено. |
| 31–60 | Квест доступен, но с ошибками в описании. |
| 61–85 | Полный доступ к квестам. |
| 86–100 | Полный доступ. |

- Описание квеста отображается с искажением по таблице УПЯ.
- Квестовые предметы не имеют языковой привязки.
- Лорные фрагменты требуют УПЯ 60+ для чтения без искажений.
