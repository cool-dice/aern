# Артефакт 32. Модерация и безопасность

## 1. Общие принципы

- Модерация — **серверная**. Гильдии и игроки не имеют права банить или мутить от имени системы.
- Безопасность — **авторитарная**. Все действия валидируются сервером. Клиент не является доверенным.
- Модерация не влияет на игровые механики: не даёт бонусов, не открывает контент, не меняет баланс.
- AI-боты — полноценные участники. Они подчиняются тем же правилам, что и игроки, но не могут быть объектом репорта со стороны игроков (так как их владелец — носитель).
- Наказания применяются к **аккаунту**, а не к персонажу. Бан аккаунта затрагивает все персонажи на нём, включая AI-бота.
- Все действия модерации логируются и доступны администрации.
- Персональные данные игроков защищены. Сбор данных минимизирован.

## 3. Инструменты модерации

### 3.1. Репорт

- Игрок может отправить репорт на другого игрока или сообщение.
- Репорт содержит: цель, причину, доказательства (лог чата, скриншот, реплей).
- Репорт попадает в очередь модерации.
- Анонимность репортёра сохраняется.
- Ложные репорты наказываются.

### 3.2. Игнорирование

- Игрок может добавить другого в чёрный список.
- Сообщения игнорируемого не отображаются.
- Игнорирование не влияет на группу, гильдию, торговлю.

### 3.3. Мьют

- Блокировка чата на 1–24 часа.
- Применяется модератором или автоматически.
- Не влияет на игру, только на чат.
- Логируется.

### 3.4. Бан чата

- Блокировка чата на 7 дней.
- Применяется модератором.
- Не влияет на игру.
- Логируется.

### 3.5. Бан аккаунта

- Временный (1–30 дней) или постоянный.
- Применяется администратором.
- Блокирует вход в игру.
- Все персонажи, включая AI-бота, блокируются.
- Логируется.

### 3.6. Автомодерация

- Спам: > 5 сообщений за 10 секунд.
- Капс: > 70% заглавных букв.
- Чёрный список слов: настраивается.
- Повторяющиеся сообщения: > 3 одинаковых за минуту.
- Ссылки: только разрешённые домены.

## 4. Каналы чата и модерация

| Канал | Кто видит | Модерация | УПЯ |
|---|---|---|---|
| **Локальный** | Все в локации | Серверная | Да |
| **Групповой** | Группа (до 4) | Серверная | Нет |
| **Гильдейский** | Гильдия | Гильдия + сервер | Нет |
| **Торговый** | Город/хаб | Серверная | Да |
| **Системный** | Все | Только сервер | Нет |
| **Личный (почта)** | Отправитель и получатель | Серверная | Да |

- Гильдейский чат: гильдия может устанавливать свои правила, но серверная модерация имеет приоритет.
- Логирование всех сообщений: 30 дней.
- Модерация не читает личные сообщения без репорта.

## 5. Безопасность

### 5.1. Аутентификация

- Регистрация по email.
- Пароль: bcrypt (cost 12), минимум 8 символов.
- Двухфакторная аутентификация (опционально).
- Токен при входе: JWT, срок 24 часа.
- Сессионный ключ: HMAC-SHA256 для команд.

### 5.2. Шифрование

- TLS 1.3 для WebSocket.
- AES-256 для резервных копий.
- Пароли не хранятся в открытом виде.

### 5.3. Античит

- Серверная валидация всех действий.
- Проверка ОД, дистанции, кулдаунов, ресурсов.
- Невозможные действия отклоняются.
- Подозрительная активность логируется.
- При повторных нарушениях — временный бан.
- Клиент не может влиять на урон, лут, позиции.

### 5.4. Защита от DDoS

- Rate limiting на уровне сервера.
- Cloudflare или аналог.
- Ограничение соединений с одного IP.
- Блокировка подозрительных IP.

### 5.5. Защита от читов

- Клиент отправляет только команды.
- Все расчёты на сервере.
- Клиент не может изменить состояние мира.
- Реплеи проверяются на аномалии.

### 5.6. Защита AI-ботов

- Инференс на клиенте носителя.
- Сервер валидирует действия бота как клиента.
- Носитель не может влиять на решения бота напрямую.
- Модификация сайдкара запрещена.
- При нарушении — бан носителя.

## 6. Защита от злоупотреблений

### 6.1. Альт-аккаунты

- Один аккаунт — один AI-бот.
- Один аккаунт — одна гильдия.
- Мультибоксинг запрещён.
- При обнаружении — бан всех аккаунтов.

### 6.2. Сговор

- Повторяющиеся войны без боя.
- Одинаковые составы.
- Быстрые победы.
- Обмен городами.
- Всё фиксируется сервером.
- Награды замораживаются до проверки.

### 6.3. Грифинг

- Кемпинг привязки: запрещён.
- Блокировка порталов: снимается через 24 часа.
- Сейф-зона радиусом 1 узел вокруг города.
- Атака в сейф-зоне запрещена.

### 6.4. Вывод ресурсов

- Лимиты на снятие из гильдбанка.
- Логирование всех операций.
- Подтверждение крупных операций.
- При подозрении — заморозка.

### 6.5. Накрутка голосов

- Один персонаж — один голос.
- AI-боты голосуют только при онлайн-носителе.
- Аномалии фиксируются.

### 6.6. Мошенничество в торговле

- Все сделки логируются.
- Аукцион: налог 5%, лимит лотов.
- Прямой обмен: без комиссии, но с логированием.
- При мошенничестве — бан.

## 7. Приватность

### 7.1. Сбор данных

- Email — для входа.
- IP — для безопасности.
- Игровые действия — для аналитики.
- Чат — для модерации.
- Платёжные данные — только через платёжные системы.

### 7.2. Хранение

- Персональные данные: PostgreSQL, шифрование AES-256.
- Обезличенная аналитика: ClickHouse, S3.
- Срок хранения: 2 года.
- Удаление по запросу игрока.

### 7.3. Доступ

- Модераторы видят только чат и репорты.
- Администраторы видят всё.
- Третьи лица не имеют доступа.
- Данные не передаются третьим лицам.

### 7.4. Согласие

- Игрок уведомлён о сборе телеметрии при первом входе.
- Игрок может отказаться от расширенной аналитики.
- Базовая телеметрия обязательна.

## 9. Процесс модерации

### 9.1. Репорт

1. Игрок отправляет репорт.
2. Репорт попадает в очередь.
3. Модератор рассматривает.
4. Принимает решение.
5. Уведомляет стороны.
6. Логирует.

### 9.2. Автомодерация

1. Система фиксирует нарушение.
2. Применяет наказание.
3. Уведомляет игрока.
4. Логирует.

### 9.3. Апелляция

1. Игрок подаёт апелляцию.
2. Администратор рассматривает.
3. Принимает решение.
4. Уведомляет игрока.
5. Логирует.

### 9.4. Сроки

| Действие | Срок |
|---|---|
| Рассмотрение репорта | 24 часа |
| Рассмотрение апелляции | 48 часов |
| Временный бан | 1–30 дней |
| Постоянный бан | Бессрочно |

## 11. Безопасность AI

### 11.1. Изоляция

- Rust-сайдкар — отдельный процесс.
- Нет доступа к личным данным игрока.
- Нет доступа к другим играм.
- IPC только с клиентом.

### 11.2. Валидация

- Все действия бота валидируются сервером.
- Невозможные действия отклоняются.
- Аномалии логируются.
- При нарушении — бан носителя.

### 11.3. Модификация

- Модификация сайдкара запрещена.
- При обнаружении — бан.
- Проверка целостности при запуске.

### 11.4. Конфиденциальность

- Модель не передаёт данные третьим лицам.
- Модель не сохраняет личные данные.
- Модель изолирована.
