# Артефакт 34. Звук и музыка

## 1. Общие принципы

- Звук — часть атмосферы, а не механика. Он не даёт бонусов и не влияет на геймплей.
- Музыка **адаптивная**: меняется в зависимости от ситуации (город, бой, данж, исследование).
- Все звуки вынесены в отдельные файлы. Хардкод запрещён.
- Громкость настраивается по каналам: музыка, эффекты, эмбиент, голос, интерфейс.
- Субтитры для важных звуков — часть системы доступности.
- AI-боты не имеют собственного звука. Их действия озвучиваются как действия игрока.
- Все звуки оптимизированы для потоковой загрузки.

## 2. Аудио-документ

### 2.1. Назначение

Аудио-документ описывает все звуки и музыкальные темы, используемые в игре. Он является эталоном для звукорежиссёра и разработчика.

### 2.2. Структура

| Раздел | Содержание |
|---|---|
| **Музыка** | Темы, жанр, инструменты, длительность |
| **Эмбиент** | Фоновые звуки локаций |
| **Бой** | Удары, выстрелы, способности |
| **Интерфейс** | Клики, уведомления, меню |
| **Мир** | Двери, сундуки, ресурсы, погода |
| **Существа** | Монстры, NPC, Хранители |
| **События** | Вторжения, боссы, праздники |
| **Голос** | Реплики NPC, крики, субтитры |

### 2.3. Формат

- Формат файлов: OGG Vorbis (основной), WAV (исходники).
- Частота дискретизации: 44.1 кГц.
- Битрейт: 128–192 кбит/с (OGG).
- Каналы: стерео (музыка), моно (эффекты).
- Громкость: нормализована до −3 dBFS.

## 3. Музыка

### 3.1. Жанр

- Тёмное техно-фэнтези.
- Синтезаторные темы, индустриальные ритмы, этнические мотивы.
- Мрачные, атмосферные, с элементами эмбиента.

### 3.2. Инструменты

| Инструмент | Использование |
|---|---|
| **Синтезаторы** | Основной фон |
| **Барабаны** | Ритм, бой |
| **Струнные** | Эмоциональные моменты |
| **Духовые** | Торжественные моменты |
| **Хор** | Лорные, эпические сцены |
| **Этнические** | Расовые темы |

### 3.3. Темы

| Тема | Где используется | Длительность |
|---|---|---|
| **Главное меню** | Меню | 2–3 мин |
| **Светлая сторона** | Города, равнины, леса | 3–5 мин |
| **Тёмная сторона** | Города, лавы, пустоши | 3–5 мин |
| **Бой** | Боевые сцены | 2–3 мин |
| **Данж** | Подземелья, руины | 3–5 мин |
| **Изначальный город** | Центр, Архив | 5–7 мин |
| **Босс** | Уникальные боссы | 3–5 мин |
| **Победа** | Завершение боя | 30 сек |
| **Поражение** | Смерть | 30 сек |
| **Праздник** | События | 2–3 мин |

### 3.4. Адаптивность

- Музыка состоит из слоёв.
- Слои включаются и выключаются в зависимости от ситуации.
- Переходы между слоями — плавные (1–2 сек).
- Пример: в бою добавляется слой барабанов и струнных.

### 3.5. Слои

| Слой | Когда включается |
|---|---|
| **Базовый** | Всегда |
| **Ритм** | Бой, опасность |
| **Мелодия** | Город, безопасность |
| **Атмосфера** | Данж, руины |
| **Напряжение** | Низкое HP, босс |
| **Победа** | Завершение боя |

## 8. Голос

### 8.1. NPC

- Реплики NPC озвучиваются.
- Язык NPC — на языке расы.
- Субтитры обязательны.
- Громкость голоса настраивается отдельно.

### 8.2. Крики

- Боевые крики.
- Крики боли.
- Крики победы.
- Крики смерти.

### 8.3. Субтитры

- Формат: `[Звук] Имя: Текст`.
- Настройки: размер, цвет, фон, позиция.
- Визуальные индикаторы для важных звуков.

## 9. Адаптивная музыка

### 9.1. Состояния

| Состояние | Музыка |
|---|---|
| **Меню** | Главная тема |
| **Город** | Спокойная, мелодичная |
| **Исследование** | Атмосферная |
| **Бой** | Ритмичная, напряжённая |
| **Босс** | Эпическая |
| **Смерть** | Траурная |
| **Победа** | Торжественная |
| **Данж** | Мрачная |
| **Изначальный город** | Таинственная |
| **Праздник** | Весёлая |

### 9.2. Переходы

- Переходы между состояниями — плавные (1–2 сек).
- Слои включаются и выключаются.
- Приоритет: бой > город > исследование.
- При низком HP — слой напряжения.

### 9.3. Реализация

- FMOD или Wwise (опционально).
- Встроенная система слоёв на Web Audio API.
- Кроссфейд между темами.

## 10. Реализация

### 10.1. Клиент

- Web Audio API.
- Howler.js (опционально).
- Загрузка звуков: потоковая.
- Кэш: LRU.
- Формат: OGG.

### 10.2. Сервер

- Сервер не воспроизводит звук.
- Сервер отправляет события.
- Клиент интерпретирует события в звуки.

### 10.3. Синхронизация

- Звуки боя синхронизированы с анимацией.
- Задержка: < 50 мс.
- При лаге — звук не воспроизводится.

### 10.4. Производительность

| Параметр | Значение |
|---|---|
| Одновременных звуков | 32 |
| Задержка | < 50 мс |
| Использование CPU | < 5% |
| Использование RAM | < 100 МБ |
