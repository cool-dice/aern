# Артефакт 26. Аналитика и телеметрия

## 1. Общие принципы

- Аналитика — инструмент разработки, а не механика игры. Она не влияет на геймплей.
- Телеметрия собирается **на сервере**. Клиент отправляет только события, необходимые для мониторинга производительности.
- Персональные данные игрока не покидают сервер в сыром виде. Аналитика работает с обезличенными идентификаторами.
- Все события имеют единый формат и хранятся централизованно.
- Сбор данных соответствует принципам минимизации: только то, что нужно для баланса, отладки и эксперимента.
- AI-боты и игроки — равноправные субъекты аналитики. Их действия логируются одинаково.
- Целевая задача аналитики — **эксперимент**: сравнить развитие мира под управлением игроков и под управлением AI-ботов.

## 3. События телеметрии

### 3.1. Формат события

```json
{
  "event": "combat.attack",
  "timestamp": 1234567890.123,
  "server_id": "shard-01",
  "session_id": "uuid",
  "actor_id": "character_uuid",
  "actor_type": "player|bot",
  "payload": { ... }
}
```

## 4. Хранение

### 4.1. Уровни хранения

| Уровень | Хранилище | Срок | Формат |
|---|---|---|---|
| **Горячий** | Redis Streams | 24 часа | JSON |
| **Тёплый** | ClickHouse | 90 дней | Колонки |
| **Холодный** | S3 (Parquet) | 2 года | Parquet |
| **Агрегаты** | PostgreSQL | Бессрочно | Таблицы метрик |

### 4.2. Поток данных

```
Сервер → Redis Streams → Воркер → ClickHouse
                                ↓
                              S3 (архив)
                                ↓
                              Агрегаты → PostgreSQL
```

### 4.3. Батчинг

- События буферизуются на сервере.
- Отправка батчами по 1000 событий или раз в 5 секунд.
- Это снижает нагрузку на хранилище.

## 8. Эксперимент: игроки против AI

### 8.1. Цель

- Сравнить развитие двух сторон континента под управлением разных типов субъектов.
- Понять, как игроки и AI принимают решения в одинаковых условиях.
- Выявить сильные и слабые стороны обеих сторон.

### 8.2. Гипотезы

| Гипотеза | Проверка |
|---|---|
| AI быстрее прогрессирует | Средний уровень по дням |
| AI эффективнее в бою | Win rate, смертность |
| Игроки лучше в социальном | Размер гильдий, войны |
| AI лучше в экономике | Оборот золота, аукцион |
| Игроки лучше в исследовании | Открытые узлы, лор |
| AI лучше в оптимизации | Крафт, лут на рейд |

### 8.3. Данные

- Все игровые метрики по обеим сторонам.
- Временные ряды по дням.
- Срезы по расам, уровням, гильдиям.
- Анонимизированные.

### 8.4. Отчётность

- Ежедневный отчёт.
- Еженедельный дайджест.
- Ежемесячный анализ.
- Публикация результатов — по усмотрению разработчика.

## 9. Приватность

### 9.1. Принципы

- Игрок не идентифицируется по имени в аналитике. Только UUID.
- Почта, пароль, платёжные данные не попадают в аналитику.
- Чат логируется для модерации, но не для аналитики без обезличивания.
- IP-адреса хранятся только для безопасности, не для аналитики.
- Данные не передаются третьим лицам.

### 9.2. Согласие

- Игрок уведомлён о сборе телеметрии при первом входе.
- Игрок может отказаться от расширенной аналитики (без влияния на игру).
- Базовая телеметрия (техническая) обязательна.

### 9.3. Хранение

- Персональные данные — в PostgreSQL, шифрование AES-256.
- Обезличенная аналитика — в ClickHouse и S3.
- Срок хранения: 2 года.
- Удаление по запросу игрока.
