# Артефакт 27. UI/UX

## 1. Общие принципы

- **ПК-первично.** Управление: клавиатура + мышь. Сенсор — пост-релиз.
- **Вид:** первое лицо, псевдо-3D, спрайты. Сетка клеток. Ориентир — dungeon crawler (Might and Magic, Wizardry, Legend of Grimrock).
- **Движение:** WASD. Поворот — мышь. Взаимодействие — клик по объекту в поле зрения.
- **Все локации — единые сцены от первого лица.** Города, хабы, рёбра, данжи, бои — всё происходит в одной и той же камере. Нет отдельных «статичных экранов».
- **Минимум текста.** Иконки + цифры. Текст — только там, где он несёт смысл.
- **Все таймеры — реальные.** Отображаются в часах, минутах, секундах.
- **Языковой барьер — часть UI.** Текст искажается в зависимости от УПЯ.
- **AI-бот не отображается в интерфейсе игрока.** Игрок не наблюдает за ботом.
- **Цветовая кодировка сторон** используется последовательно.
- Интерфейс масштабируется, поддерживает разрешения от 1280×720 до 4K.
- Поддержка colorblind mode, ребинда клавиш, изменения размера шрифта.

## 2. Визуальный стиль

### 2.1. Палитра

| Элемент | Цвет |
|---|---|
| **Светлая сторона** | Светлые тона: песочный, зелёный, серо-голубой |
| **Тёмная сторона** | Тёмные тона: багровый, чёрный, обсидиановый |
| **Нейтральные** | Зелёный, серый |
| **Хранители** | Мигающий золотой |
| **Опасность** | Красный |
| **Предупреждение** | Жёлтый |
| **Успех** | Зелёный |
| **Информация** | Синий |

### 2.2. Шрифты

- Основной: моноширинный без засечек (например, JetBrains Mono).
- Заголовки: тот же шрифт, увеличенный.
- Размеры: 12, 14, 16, 20, 24, 32 px.
- Масштабирование: пользовательское (100%, 125%, 150%).

### 2.3. Иконки

- Единый стиль: линейные, минималистичные.
- Размеры: 16, 24, 32, 48 px.
- Цветовые состояния: обычное, активное, отключённое, опасное.

### 2.4. Анимации

- Длительность: 100–300 мс.
- Плавные переходы между экранами.
- Отключаемые в настройках (для слабых ПК).

## 5. Создание персонажа

### 5.1. Шаги

1. **Выбор расы.** Сетка из 8 рас с описанием, бонусами, биомом.
2. **Распределение статов.** 20 очков на 6 статов. Максимум 10 на стат.
3. **Внешность.** Цвет кожи, волос, глаз, рост, телосложение, рога, уши, татуировки, шрамы.
4. **Имя.** Ввод имени.
5. **Чистый.** Чекбокс «Чистый» (отказ от реликтов).
6. **Подтверждение.** Просмотр итогов.

### 5.2. Особенности

- Расчёт производных статов (HP, ОД, НН) в реальном времени.
- Предпросмотр персонажа.
- Кнопка «Случайно» для быстрого создания.
- Кнопка «Сброс».

## 6. Игровая сцена (первое лицо)

### 6.1. Принцип

Все локации — города, хабы, рёбра, данжи, бои — отображаются в **одной камере от первого лица**. Игрок перемещается по клеткам, поворачивается мышью, взаимодействует с объектами в поле зрения.

### 6.2. Компоновка

```
┌──────────────────────────────────────────┐
│ Верхняя панель: HP, ОД, НН, золото, уровень│
├──────────────────────────────────────────┤
│                                          │
│                                          │
│         Первое лицо. Спрайты.            │
│         Сетка клеток невидима,           │
│         но движение по ней.              │
│                                          │
│         В центре — прицел.               │
│         Внизу — подсказки взаимодействия.│
│                                          │
│                                          │
├──────────────────────────────────────────┤
│ Нижняя панель: [Инвентарь] [Квесты]      │
│ [Карта] [Чат] [Меню]                     │
└──────────────────────────────────────────┘
```

### 6.3. Элементы

| Элемент | Функция |
|---|---|
| **HP / ОД / НН** | Текущее состояние |
| **Золото** | Кошелёк |
| **Уровень** | Прогресс |
| **Прицел** | Центр экрана |
| **Подсказка** | «[E] Поговорить», «[ЛКМ] Атаковать» |
| **Мини-карта** | В углу, если есть |
| **Чат** | Локальный чат в углу |

### 6.4. Взаимодействие

| Действие | Как |
|---|---|
| **Движение** | WASD (шаг вперёд/назад/влево/вправо) |
| **Поворот** | Мышь |
| **Взаимодействие** | Клик по объекту или E |
| **Атака** | ЛКМ по врагу |
| **Прицел** | ПКМ по врагу → меню конечностей |
| **Способности** | 1, 2, 3 |
| **Инвентарь** | I |
| **Карта** | M |

### 6.5. Город

- Полноценная локация от первого лица.
- По городу ходят NPC, другие игроки, AI.
- Здания: ратуша, кузня, библиотека, аукцион, хранилище, портал, привязка.
- Вход в здание — через дверь.
- NPC стоят в зданиях или на улицах.
- Сейф-зона: PvP запрещён.

### 6.6. Хаб

- Малый узел от первого лица.
- Перекрёсток с выходами на рёбра.
- КПП на выходах.
- Доска квестов.
- Возможны бои (PvP открыт).

### 6.7. Ребро

- Процедурный мини-данж от первого лица.
- 3–7+ комнат.
- Тупики, развилки, события.
- Возможны бои.

### 6.8. Данж

- Процедурная локация от первого лица.
- 5–30 комнат.
- Ловушки, лут, боссы.
- Секреты.

## 7. Боевой интерфейс

### 7.1. Компоновка

```
┌──────────────────────────────────────────┐
│ HP [████████░░] 80/100  ОД: 5/10         │
│ Статусы: [Горение] [Кровотечение]        │
├──────────────────────────────────────────┤
│                                          │
│         Первое лицо. Враги в поле зрения.│
│         Портреты союзников — по бокам.   │
│         Снизу — панель действий.         │
│                                          │
├──────────────────────────────────────────┤
│ [Атака] [Прицел] [Способность 1]         │
│ [Способность 2] [Предмет] [Взаимодействие]│
└──────────────────────────────────────────┘
```

### 7.2. Элементы

| Элемент | Функция |
|---|---|
| **HP bar** | Текущее HP |
| **ОД bar** | Текущие ОД |
| **Статусы** | Активные эффекты |
| **Портреты союзников** | HP, статусы |
| **Враги** | HP, статусы |
| **Кнопки действий** | Атака, способности, предметы |
| **Мини-карта** | Позиции |

### 7.3. Прицеливание

- ПКМ по врагу → меню конечностей: голова, торс, руки, ноги.
- Штраф к точности отображается.
- +1 ОД к стоимости.

### 7.4. Побег

- **Кнопки «Отход» нет.**
- Побег — только физический: разорвать дистанцию, выйти из зоны боя.
- Индикатор дистанции до врагов отображается.
- Если враги не преследуют — побег успешен.
- Если преследуют — нужно оторваться.

## 17. Карта

### 17.1. Компоновка

```
┌──────────────────────────────────────────┐
│ [Регион ▼] [Уровни ▼]                    │
├──────────────────────────────────────────┤
│                                          │
│   Статичная картинка материка            │
│   Поверх — граф узлов и рёбер            │
│                                          │
│   Туман войны:                           │
│   • Текущий узел — виден                 │
│   • Соседние узлы — видны, но без деталей│
│   • Выходы с соседних узлов — не видны   │
│   • Неисследованные — серые              │
│                                          │
├──────────────────────────────────────────┤
│ Легенда: [Город] [Хаб] [Данж] [Ресурс]  │
└──────────────────────────────────────────┘
```

### 17.2. Туман войны

- **При первом входе в стартовый город:** видны все выходы города и соседние узлы.
- **Соседние узлы:** отображаются как точки, но их тип и выходы не видны.
- **При входе в узел:** открываются его выходы и соседние узлы.
- **Неисследованные узлы:** серые, без деталей.
- **Исследованные узлы:** цветные, с типом и выходами.
- **Текущий узел:** пульсирует.

### 17.3. Особенности

- Карта открывается по мере исследования.
- Порталы отмечены.
- Владельцы узлов отмечены цветом гильдии.

## 19. Мини-игра взлома

### 19.1. Компоновка

```
┌──────────────────────────────────────────┐
│ Взлом Хранителя (Страж)                  │
│ Сложность: 20 − Техника/2 = 15           │
│ Попытки: 3                               │
├──────────────────────────────────────────┤
│   A  B  C  D                             │
│ 1 █  ▓  ▒  ░                             │
│ 2 ▓  █  ░  ▒                             │
│ 3 ▒  ░  █  ▓                             │
│ 4 ░  ▒  ▓  █                             │
├──────────────────────────────────────────┤
│ Подсказка: 2 символа на своих местах     │
│ Ввод: [____]                             │
│ [Проверить] [Отмена]                     │
└──────────────────────────────────────────┘
```

### 19.2. Особенности

- Сетка 4×4.
- 3 попытки.
- Проверка Техники снижает сложность.
- Провал — атака Хранителя.
