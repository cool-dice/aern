# Артефакт 16. Социальные механики

## 1. Общие принципы

- Социальные механики — это чат, группы, торговля, титулы, доктрины, контракты, модерация и личная репутация с NPC.
- Гильдии и войны описаны в отдельном документе.
- Фракций как системы нет. Есть гильдии, титулы и NPC-отношения.
- Языковой барьер действует во всех каналах, кроме технических.
- Время в игре — только реальное.

---

## 2. Каналы чата

| Канал | Кто видит | Требует УПЯ | Модерация |
|---|---|---|---|
| **Локальный** | Все в локации | Да | Серверная |
| **Групповой** | Члены группы (до 4) | Нет | Серверная |
| **Гильдейский** | Члены гильдии | Нет | Гильдия + сервер |
| **Торговый** | Город или хаб | Да | Серверная |
| **Системный** | Все | Нет | Только сервер |
| **Личный (почта)** | Отправитель и получатель | Да | Серверная |

- Глобального чата нет. Языковой барьер — часть мира.
- Гильдейский и групповой — технические каналы, УПЯ не требуется.
- Локальный и торговый — требуют УПЯ. При низком УПЯ текст искажается.

---

## 3. Модерация чата

| Действие | Длительность | Кто применяет |
|---|---|---|
| Репорт на сообщение | — | Игрок |
| Мьют | 1–24 часа | Сервер или модератор |
| Бан чата | 7 дней | Модератор |
| Автопроверка на спам | Мгновенно | Сервер |
| Автопроверка на капс | Мгновенно | Сервер |
| Чёрный список слов | Настраивается | Сервер |

- Модерация — серверная, не гильдейская.
- Логирование всех сообщений.
- Повторные нарушения — временный бан аккаунта.

## 4. Поиск группы (LFG)

### 4.1. Способы

| Способ | Описание |
|---|---|
| **Автоматический** | Кнопка «Найти группу», подбор по уровню и роли |
| **Ручной** | Приглашение через чат или список игроков в хабе |
| **Гильдейский** | Приглашение членов гильдии |

### 4.2. Роли

| Роль | Описание |
|---|---|
| **Танк** | Высокое HP, броня, удержание |
| **Дамагер** | Высокий урон |
| **Поддержка** | Лечение, баффы, ремонт |
| **Универсал** | Гибрид |

### 4.3. Ограничения

- Группа до **4** человек.
- Лидер группы — создатель.
- Прогресс квестов общий.
- Опыт делится поровну.

## 5. Торговля

### 5.1. Способы

| Способ | Комиссия | Описание |
|---|---|---|
| **Прямой обмен** | Нет | Между игроками |
| **Аукцион** | 5% | В городе, лот 24 часа |
| **NPC-торговцы** | — | Покупка 150%, продажа 50% |
| **Бартер** | Нет | Золото, реликты, ресурсы |

### 5.2. Аукцион

- Лимит лотов: 5 на игрока.
- Ставки: шаг 5% от стартовой цены.
- Выкуп: мгновенная покупка.
- Налог 5% с продавца.
- В нейтральном городе налог уходит в системный сток.
- В городе под контролем гильдии — в гильдбанк.

## 6. Титулы

### 6.1. Принципы

- Титул выдаёт **гильдия**, не система.
- Титул можно выдать **любому игроку**, даже не члену гильдии.
- Титул виден **только членам гильдии-эмитента**.
- Один игрок может иметь несколько титулов от разных гильдий.
- Титул снимается голосованием гильдии.
- Титул не влияет на лут, цены, опыт.

### 6.2. Эффекты

| Тип титула | Эффект |
|---|---|
| **Позитивный** | Бафф для членов гильдии при взаимодействии с носителем |
| **Негативный** | Дебафф, метка, награда за голову |
| **Нейтральный** | Информационная метка |

### 6.3. Примеры

| Титул | Эффект |
|---|---|
| **Крыса** | Метка, члены гильдии могут атаковать без штрафа |
| **Союзник** | Доступ к узлам и гильдбанку по запросу |
| **Предатель** | Награда за голову |
| **Мастер** | +5% к крафту для членов гильдии при обмене |
| **Должник** | Метка, гильдия видит долг |

## 7. Доктрины

### 7.1. Принципы

- Доктрина — глобальный бонус гильдии.
- Открывается за золото и ресурсы.
- Действует на всех членов гильдии.
- Одна активная доктрина на гильдию.
- Смена доктрины — раз в 7 реальных дней.

### 7.2. Примеры

| Доктрина | Эффект | Стоимость |
|---|---|---|
| **Ярость** | +5% к урону | 50 000 золота, 500 металла |
| **Стойкость** | +5% к HP | 50 000 золота, 500 кожи |
| **Труд** | +5% к скорости добычи | 50 000 золота, 500 дерева |
| **Алчность** | +5% к золоту | 100 000 золота |
| **Знание** | +5% к опыту | 100 000 золота, 500 кристаллов |
| **Защита** | +5% к броне | 50 000 золота, 500 титана |

## 8. Контракты

### 8.1. Принципы

- Доска контрактов в хабах и городах.
- Заказчик — игрок или гильдия.
- Цель — убийство, кража, контрабанда, защита.
- Награда — золото, ресурсы, реликты.
- Срок — реальное время.
- Анонимность — опционально.
- Контракты не считаются в лимит активных квестов.

### 8.2. Типы контрактов

| Тип | Цель | Награда |
|---|---|---|
| **Убийство** | Убить игрока или AI-бота | Золото, ресурсы |
| **Кража** | Украсть предмет | Золото, реликты |
| **Контрабанда** | Доставить груз | Золото |
| **Защита** | Удержать узел N минут | Золото, ресурсы |
| **Разведка** | Собрать данные | Золото |

### 8.3. Ограничения

- Нельзя заказать убийство члена своей гильдии.
- Нельзя заказать убийство игрока ниже 10-го уровня.
- Награда за голову видна только членам гильдии-заказчика.

## 9. Личная репутация с NPC

### 9.1. Принципы

- Репутации с фракциями нет.
- Есть **личная репутация** с каждым NPC (0–100).
- Растёт за выполнение квестов NPC.
- Падает за атаку NPC или провал квеста.
- Влияет на диалоги, скидки, доступ к квестам.
- Видна только игроку.

### 9.2. Шкала

| Репутация | Эффект |
|---|---|
| **0–20** | NPC отказывает в квестах |
| **21–40** | NPC даёт базовые квесты |
| **41–60** | NPC даёт все квесты, скидка 5% |
| **61–80** | Скидка 10%, доступ к редким квестам |
| **81–100** | Скидка 15%, доступ к уникальным квестам |

### 9.3. Изменение

| Событие | Изменение |
|---|---|
| Выполнение квеста NPC | +5 |
| Провал квеста NPC | −2 |
| Атака NPC | −10 |
| Подарок NPC | +3 |
