# Артефакт 28. Схемы и графики

## 1. Общие принципы

- Все схемы выполнены в текстовом (ASCII) виде. При реализации заменяются на графические диаграммы.
- Диаграммы описывают: архитектуру, потоки данных, состояния, баланс, экономику, прогрессию.
- Каждая схема самодостаточна и не требует дополнительных пояснений.
- Все числовые данные соответствуют утверждённым артефактам.
- Схемы используются как эталон при разработке, тестировании и документировании.
