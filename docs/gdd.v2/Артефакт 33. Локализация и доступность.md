# Артефакт 33. Локализация и доступность

## 1. Общие принципы

- Локализация — часть продукта, а не надстройка. Все тексты вынесены в JSON-файлы.
- Доступность — обязательное требование, а не опция.
- Приоритет языков: RU (основной), EN (пост-релиз), CN (пост-релиз, при спросе).
- Все тексты локализуются через ключи. Хардкод запрещён.
- Плюрализация, форматирование чисел и дат — через i18n-библиотеку.
- Доступность (a11y) закладывается в UI с самого начала.

## 3. Формат локализации

### 3.1. JSON-файлы

```json
{
  "ui": {
    "menu": {
      "play": "Играть",
      "settings": "Настройки",
      "exit": "Выход"
    }
  },
  "quests": {
    "kill_rats": {
      "title": "Убить 10 крыс",
      "description": "Крысы-спороносы заполонили подвалы.",
      "objectives": {
        "kill": "Убить крыс: {current}/{target}"
      }
    }
  }
}
```

### 3.2. Ключи

- Формат: `категория.подкатегория.ключ`.
- Пример: `ui.menu.play`, `quests.kill_rats.title`.
- Ключи уникальны.
- Ключи не содержат пробелов и спецсимволов.

### 3.3. Плюрализация

```json
{
  "rats": {
    "one": "{count} крыса",
    "few": "{count} крысы",
    "many": "{count} крыс"
  }
}
```

- Для русского: one, few, many, other.
- Для английского: one, other.
- Для китайского: other.

### 3.4. Форматирование

- Числа: `{value, number}`.
- Даты: `{value, date, short}`.
- Время: `{value, time, short}`.
- Валюта: `{value, currency, RUB}`.

### 3.5. Плейсхолдеры

- `{name}` — имя.
- `{count}` — количество.
- `{target}` — цель.
- `{current}` — текущее значение.
- Экранирование: `\{`, `\}`.

## 4. Процесс локализации

### 4.1. Этапы

1. **Экстракция.** Автоматическое извлечение строк из кода в JSON.
2. **Перевод.** Ручной или машинный.
3. **Ревью.** Проверка носителем языка.
4. **Интеграция.** Загрузка в игру.
5. **Тестирование.** Проверка отображения.

### 4.2. Инструменты

| Инструмент | Назначение |
|---|---|
| **i18next** | Библиотека i18n для React |
| **react-i18next** | Интеграция с React |
| **Lokalise** | Управление переводами (опционально) |
| **Crowdin** | Управление переводами (опционально) |

### 4.3. Версионирование

- Каждый язык — отдельная папка: `locales/ru/`, `locales/en/`.
- Каждый файл — отдельный неймспейс: `ui.json`, `quests.json`.
- Версионирование в Git.

### 4.4. Обновление

- При добавлении ключей — обновляются все языки.
- Отсутствующие ключи — fallback на русский.
- При релизе — финальная проверка.

## 5. Языковой барьер в игре

### 5.1. УПЯ и локализация

- УПЯ — внутриигровая механика, не связанная с языком интерфейса.
- Текст на чужом языке отображается с искажениями по УПЯ.
- При УПЯ 100 — полный перевод.
- При УПЯ 0 — 90% символов заменены.

### 5.2. Древний язык

- Не переводится.
- Шифр расшифровывается игроком вручную.
- Для ботов — структурированный поток данных.

### 5.3. Интерфейс

- UI всегда на выбранном языке игрока.
- Язык NPC — на языке расы.
- Чат — на языке отправителя, с искажением по УПЯ.

## 7. UI-адаптация

### 7.1. Разрешения

| Разрешение | Поддержка |
|---|---|
| 1280×720 | Минимум |
| 1920×1080 | Рекомендуется |
| 2560×1440 | Поддержка |
| 3840×2160 | Поддержка |

### 7.2. Масштабирование

- UI масштабируется пропорционально.
- Мини-карта и чат закреплены по углам.
- Панели скрываются в бою.
- Размер шрифта настраивается отдельно.

### 7.3. Цветовые схемы

| Схема | Описание |
|---|---|
| **Стандартная** | Светлая сторона — светлые тона, тёмная — тёмные |
| **Протанопия** | Красный → синий, зелёный → жёлтый |
| **Дейтеранопия** | Красный → оранжевый, зелёный → жёлтый |
| **Тританопия** | Синий → зелёный, жёлтый → розовый |
| **Высокий контраст** | Чёрно-белая с акцентами |
