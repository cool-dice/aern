# Артефакт 3. Языки и УПЯ

## 1. Общие принципы

- Язык — барьер между сторонами континента.
- Каждый персонаж имеет **Уровень Понимания Языка (УПЯ)** от 0 до 100 для каждого языка отдельно.
- УПЯ влияет на речь, чтение, крафт, квесты, чат и интерфейс.
- Все тексты в игре (книги, квесты, чат, вики) привязаны к языку.
- Автоматический перевод отсутствует. Понимание зависит только от знаний персонажа.

---

## 2. Шкала УПЯ

| УПЯ | Понимание | Речь | Технология |
|---|---|---|---|
| **0–10** | Отдельные слова | Не говорит | Маленькая модель, шаблоны |
| **11–30** | Простые фразы | Ломаная речь | Маленькая модель + LLM-переписывание |
| **31–60** | Общий смысл | С акцентом, ошибки | LLM с ограниченным словарём |
| **61–85** | Свободный разговор | Лёгкий акцент | LLM без ограничений |
| **86–100** | Полное владение | Носитель | LLM без ограничений |

---

## 3. Отображение текста при разном УПЯ

Текст, написанный на языке, который персонаж знает не полностью, искажается:

| УПЯ | Отображение |
|---|---|
| **0–10** | 90% символов заменены на случайные. Понятны только отдельные буквы. |
| **11–30** | 60% замен. Понятны короткие слова и цифры. |
| **31–60** | 30% замен. Понятен общий смысл, но с ошибками. |
| **61–85** | 10% замен. Текст читается, но с ошибками. |
| **86–100** | 0% замен. Текст отображается полностью. |

---

## 4. Скорость роста УПЯ

| Метод | Прирост УПЯ | Условия |
|---|---|---|
| **Пассивно** | +1 за 2 часа | Рядом с носителями языка |
| **Сделка/квест** | +2 | Успешное взаимодействие |
| **Учитель** | +5 | 1 час, 100 золота, не более 1 занятия в день на язык |
| **Книга** | +3 | Одноразово, 10 минут чтения |
| **Руины** | +10 | Одноразово, мини-игра |

---

## 5. Методы изучения

### 5.1. Учителя

- Находятся в городах (библиотеки, гильдии).
- Стоимость: 100 золота за занятие.
- Максимальный УПЯ от учителя: 80.
- Ограничение: 1 занятие в день на язык.

### 5.2. Книги

- Предметы, находятся в данжах, продаются.
- При использовании: +3 УПЯ, исчезает.
- Требует 10 минут игрового времени.
- Можно читать только язык, которому соответствует книга.

### 5.3. Лингвистические руины

- Одноразовые объекты в данжах Предтеч.
- При взаимодействии: мини-игра на сопоставление символов (3 попытки).
- Успех: +10 УПЯ к выбранному языку.
- Провал: +1 УПЯ.

## 6. Древний язык

### 6.1. Концепция

Древний язык — наследие Предтеч. Это не просто язык, а **реальная головоломка для игрока**. Игрок должен разгадать шифр вне игры, чтобы получить лорные фрагменты и полезную информацию. Для ботов Древний язык — это структурированный поток данных, который они могут использовать.

### 6.2. Механика разгадывания

1. **Фрагменты.** В данжах Предтеч игрок находит фрагменты текста на Древнем языке. Они выглядят как зашифрованный текст (например, `X7#9@!`).
2. **Ключи.** Рядом с фрагментами находятся ключи — символы, которые соответствуют буквам. Ключи могут быть в виде:
   - Рисунков на стенах.
   - Записей в других данжах.
   - Подсказок от NPC (редко).
3. **Шифр.** Используется подстановочный шифр или шифр Цезаря с уникальным сдвигом для каждого сервера. Игрок должен сопоставить символы и буквы.
4. **Сборка.** Расшифровав фрагмент, игрок получает текст на русском (или английском) языке. Это может быть:
   - Лорная история (что произошло с Предтечами).
   - Координаты тайников.
   - Рецепты уникальных предметов.
   - Пароли к хранилищам.
5. **Награда.** Полученные знания игрок может:
   - Использовать для прохождения.
   - Продать другим игрокам.
   - Записать в вики.

### 6.3. Награда для ботов

Для ботов Древний язык — это JSON-объекты, содержащие полезную информацию. Боты не разгадывают шифр, а сразу получают данные. Пример:

```json
{
  "event": "ancient_record",
  "location": "node_42",
  "content": {
    "lore": "Предтечи создали Разлом...",
    "coordinates": {"x": 120, "y": 45},
    "recipe": "energy_blade",
    "password": "X7#9@!"
  },
  "confidence": 0.9
}
```

Боты могут обмениваться этими данными с людьми. Если бот встречает игрока и игрок рассказывает что-то новое, бот записывает это как «источник: неизвестное существо, доверие: среднее».

### 6.4. Как игроки в реале разгадывают

- Игрок выписывает символы и предполагаемые буквы.
- Использует частотный анализ (если шифр простой).
- Ищет закономерности в повторяющихся символах.
- Сопоставляет с ключами, найденными в игре.
- Может использовать внешние инструменты (ручка, бумага, программы), но не может загуглить, так как шифр уникален для сервера.

---

## 7. Чат и автоматический перевод

- Игрок пишет на своём языке. Бот пишет на своём.
- Слушатель видит сообщение в зависимости от своего УПЯ к языку отправителя:
  - **УПЯ 0** — сообщение выводится на языке отправителя (непонятно).
  - **УПЯ 100** — сообщение автоматически переводится на родной язык слушателя.
  - **Промежуточные значения** — текст искажается согласно таблице отображения.
- Пример: игрок-человек (УПЯ тёмного = 0) получает сообщение от демона на тёмном. Он видит тёмный текст. Если УПЯ тёмного = 100, он видит перевод на светлый.

---

## 8. Влияние УПЯ на NPC, квесты, крафт

| УПЯ | Доступ |
|---|---|
| **0–30** | NPC могут отказать в квесте. Квесты с ошибками. |
| **31–60** | Квесты доступны, но с ошибками в описании. |
| **61–85** | Полный доступ к квестам. |
| **86–100** | Полный доступ. |

- **Крафт:** рецепты написаны на языке. Если УПЯ <60, рецепт непонятен. При УПЯ 60+ можно крафтить.

---

## 9. API для ботов (вики, обмен знаниями)

Боты пишут структурированные записи в общую базу знаний.

Формат записи:

```json
{
  "action": "move_north",
  "from": "node_42",
  "result": "node_17",
  "tags": ["forest", "hellhounds", "danger_high"],
  "confidence": 0.8,
  "author": "bot_1337"
}
```

Другой бот читает: «на север от узла 42 — лес с адскими псами, опасно».

Человек может читать структурированные записи (если умеет). Бот может читать прозу (если LLM позволяет).

Рейтинг: у людей — голоса, у ботов — частота подтверждений.

## 10. Отображение в интерфейсе

- В профиле персонажа: список языков с полосками прогресса.
- При наведении: точное значение УПЯ.
- Чат: искажение текста в зависимости от УПЯ.

|---|---|

| Максимальный УПЯ от учителя | 80 |

| Лимит занятий | 1 в день на язык |

## 12. Язык и гильдии

- Гильдейский чат не требует знания языка (технический канал).
- Локальный чат требует знания языка.
