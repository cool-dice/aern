## Цель

Начислять опыт, поднимать уровень до 50 и выдавать одно очко стата за уровень.

## Контекст

Артефакт 14.

Опыт до следующего уровня N (текущий уровень N, переход N → N+1): `floor(100 * N ** 1.5)`.

Контрольные суммы из документа:

| Переход | Опыт |
|---|---|
| 1→2 | 100 |
| 2→3 | 282 |
| 3→4 | 519 |
| 4→5 | 800 |
| 5→6 | 1118 |
| 10→11 | 3162 |
| 20→21 | 8944 |
| 49→50 | 35355 |

После 50 опыт не копится.

Опыт монстра: `monsterLevel * 10 + bonus`, bonus обычный 0, элитный 5, элитный босс 50, уникальный босс 100. Делится поровну между участниками (нанесли урон или хил/бафф), округление вниз на человека, остаток от деления отбрасывается, не уходит одному.

PvP: свой уровень 20; цель на 1–5 ниже — 10; на 6–10 ниже — 5; на 11+ ниже — 0; цель выше — `20 + diff * 2`. Кулдаун на ту же жертву 10 минут (`600_000` мс). Офлайн-бот опыта не даёт. Убийство онлайн-бота даёт опыт убийце.

Исследование: первый узел 10, первый данж 50, лорный фрагмент 100, Изначальный город 500. Повтор 0.

Крафт в этот опыт не идёт.

Смерть опыт не снимает.

На уровне также открываются слоты программ `floor(level / 3)` — функция уже в задаче 009, здесь не дублировать. Награды тиров предметов: уровень ≥ 10 тир 2, ≥ 20 тир 3, ≥ 30 тир 4, ≥ 40 тир 5, иначе тир 1. Тир 5 доступен с 40, уникальный контент Изначального — флаг `level === 50`.

Новое очко за уровень кладётся в `unspent`. Трата: не больше 10 суммарных очков в одном стате за всю жизнь, итог через кап задачи 005 не считается здесь. Эта функция только проверяет лимит очков, расовый модификатор применяет вызывающий через `finalStat`.

## Решение противоречий

Уровень прототипа 20 не обрезает кривую. Формула `100 * N^1.5` считается в JS number; тесты сверяют таблицу, не более точную дробь.

## Алгоритм

- `grantXp` на 50 уровне возвращает тот же объект по значению (xp 0).
- Пока xp ≥ порога и level < 50: вычесть порог, level += 1, unspent += 1. Несколько уровней за один грант возможны.
- `spendPoint`: unspent 0 → `none`. points[stat] ≥ 10 → `stat_cap`. Иначе очко переходит в points.
- `pvpXpAllowed`: нет метки или `now - last >= 600_000`.
- Отрицательный amount — `RangeError`.

## Тесты

- таблица переходов из контекста, все перечисленные числа.
- `floor(100 * 15 ** 1.5)` совпадает с функцией для уровня 15 (5809, если формула документа верна: 100 * 15^1.5 = 100 * 58.094 = 5809). Проверить в тесте ожиданием 5809.
- монстр 2 обычный → 20. Элита → 25. Уникальный босс 45 → 550.
- split 100 на 3 → 33. На 0 участников бросает RangeError.
- pvp равные уровни → 20. Жертва −4 → 10. −7 → 5. −11 → 0. Жертва +3 → 26.
- 250 опыта с 1 уровня: уровень 2 и остаток 150, unspent 1. Документ: 1→2 стоит 100, значит остаток 150, до 3 нужно 282, уровень остаётся 2.
- пачка опыта, достаточная для двух уровней, даёт unspent 2.
- 50 уровень игнорирует новый опыт.
- одиннадцатое очко в стат → `stat_cap`, unspent не уменьшается.
- тиры на уровнях 1, 10, 20, 30, 40, 50 → 1, 2, 3, 4, 5, 5.
- кулдаун 599_999 мс запрещает, 600_000 разрешает.
