## Цель

Очередь команд, подпись, реконнект с бэкоффом и предсказание только шагов.

## Контекст

Артефакты 23 и 24. Предсказание движения 500 мс. Атаки не предсказывать: локальный hp не меняется от `attack_*`. Расхождение клетки с сервером — откат к серверной клетке и повтор неподтверждённых шагов, которые моложе 500 мс. Старше отбросить.

Интерполяция других сущностей: задержка 100 мс. Функция `interpolate(a, b, t)` линейная по x,y, t в 0..1.

Реконнект: задержки 200, 400, 800, 1600, 3000 мс, дальше 3000. Счётчик попыток. Успех сбрасывает. Это чистая функция `nextDelay(attempt)`.

Сокет в тесте — фейк `{ send, close }` без сети.

Дубликаты: seq монотонный с 1.

## Решение противоречий

Буфер 500 мс из артефакта 24, не 200 мс экстраполяции. Экстраполяция чужих сущностей до 200 мс — отдельная функция `extrapolate`, если пакет опоздал: продолжить скорость последней разницы не дольше 200 мс, затем стоять.

## Интерфейсы

```ts
export function nextDelay(attempt: number): number;
export function reconcile(input: {
  serverCell: { x: number; y: number };
  pending: { seq: number; dir: Dir; atMs: number }[];
  nowMs: number;
  reaction: number;
  inCombat: boolean;
  od: number;
}): { cell: { x: number; y: number }; pending: typeof input.pending };
export function enqueue(command: ClientCommand, sessionKeyHex: string): SignedEnvelope;
```

`reconcile` применяет `move` домена к копии клетки для pending с `now-at <= 500`.

## Алгоритм

- Атака в pending не хранится. `noteLocal` игнорирует action не step/run.
- Если шаг домена возвращает ошибку, он выпадает из pending.
- Подпись через ту же каноническую строку, что протокол. Клиент может продублировать HMAC на WebCrypto недоступном в node: использовать `node:crypto` в пакете клиента допустимо в тестах node. Вынести `sign` в функцию, которую тест сверяет с `@rift/protocol` каноном и с эталоном crypto.

## Тесты

- delays: 200, 400, 800, 1600, 3000, 3000 на попытке 6.
- сервер вернул клетку старта, один pending шаг на север, реакция 10 → клетка сдвинута на 1. Pending старше 500 мс не применяется.
- атака не меняет hp в отдельной функции `applyLocal(action, state)`: hp тот же.
- enqueue ставит signature длиной 64 hex.
- интерполяция середины (0,0)-(10,0) при t 0.5 → (5,0).

## Definition of done

Тесты не открывают WebSocket-сервер. Фейк транспорта в памяти.
