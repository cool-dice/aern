# Генерация данжа по сиду

- id: `020`
- title: Генерация данжа по сиду
- status: `done`
- depends_on: `002`

## Цель

Из сида построить связный граф комнат малого, среднего, большого или рейдового данжа.

## Контекст

Артефакт 18.

Размеры:

| Размер | Комнат | Кластеров | Дорог | Боссов | Секретов |
|---|---|---|---|---|---|
| small | 5–7 | 2–3 | 1–2 | 1 | 1 |
| medium | 8–12 | 3–4 | 2–3 | 1 | 1–2 |
| large | 13–20 | 4–6 | 3–5 | 1 | 2–3 |
| raid | 21–30 | 6–8 | 5–7 | 2 | 3–4 |

Комнаты: малая 5×5, средняя 10×10, большая 15×15, арена 20×20, коридор ширина 1–3 и длина 5–15. Для старта достаточно логической сетки: клетка комнаты не обязана быть пикселем, но ширина и высота задаются.

Типы комнат и целевые доли: combat 0.40, loot 0.15, trap 0.10, event 0.10, boss 0.05, transition 0.10, empty 0.10. После назначения долей принудительно: ровно N боссов на аренах, ровно один вход `empty` или `transition` помечен `entrance`, путь от входа до каждого босса существует. Секреты — дополнительные комнаты сверх минимума, не разрывают основной путь.

Сид: `hashSeed(nodeId + '|' + groupId + '|' + windowStartIso)`. Окно общего сида 5 минут. Лимит 8 игроков на сид. Группа до 4 всегда один сид. Функция `sameWindow(aMs, bMs)` истинна, если оба попадают в один бакет `floor(ms / 300_000)`.

Сложность множители: easy 0.75/0.75, normal 1/1, hard 1.5/1.25, epic 2/1.5, raid 3/2 для HP и урона. Лут и опыт: easy 0.75, normal 1, hard 1.5, epic 2, raid 3.

Инстанс живёт 10 минут после выхода последнего. Это константа `INSTANCE_TTL_MS = 600_000` для сервиса, генератор её только экспортирует.

Проверка: нет комнаты вне компоненты входа, есть босс, нет висячего ребра.

## Решение противоречий

«Короткое окно» v1 равно 5 минутам артефакта 18. Респавна данжа нет.

## Интерфейсы

```ts
export type DungeonSize = 'small' | 'medium' | 'large' | 'raid';
export type RoomKind = 'combat' | 'loot' | 'trap' | 'event' | 'boss' | 'transition' | 'empty' | 'secret';
export interface Room { id: number; kind: RoomKind; w: number; h: number; x: number; y: number }
export interface DungeonLayout { rooms: Room[]; edges: [number, number][]; entranceId: number; bossIds: number[] }

export function generateDungeon(seedText: string, size: DungeonSize): DungeonLayout;
export function sameSeedWindow(aMs: number, bMs: number): boolean;
export function difficultyMultipliers(id: 'easy' | 'normal' | 'hard' | 'epic' | 'raid'): { hp: number; damage: number; loot: number; xp: number };
```

## Алгоритм

1. `rng = mulberry32(hashSeed(seedText))`.
2. Число комнат: минимум + `nextInt(max - min + 1)`.
3. Собрать цепь от входа до первого босса длиной не меньше 3, остальные комнаты ответвлениями от случайной уже добавленной, чтобы граф был деревом плюс ровно `roads` дополнительных рёбер между существующими комнатами, если они не создают петлю короче 0 — петли разрешены этими рёбрами.
4. Назначить виды по квотам, округляя наибольший остаток, затем заменить нужные на boss и одну на entrance.
5. Координаты: укладка вправо по BFS-слоям, шаг x = 20, y по индексу в слое * 20. Пересечения прямоугольников не обязательны к нулю, но центры уникальны.
6. Секреты добавить комнатами с ребром к случайной не-босс комнате.
7. Постпроверка связности BFS. Если босс недостижим — это баг генератора, бросить Error (тест не должен ловить его на 20 семенах).

## Тесты

- один seed и size дают глубокое равенство двух генераций.
- другой seed меняет хотя бы координату или вид.
- small содержит 5..7 обычных комнат плюс 1 секрет, ровно 1 босс, вход достижим до босса.
- raid содержит 2 босса, оба достижимы, комнат в диапазоне с учётом секретов: базовые 21–30 плюс 3–4 секрета. Зафиксировать: секреты сверх максимума базовых комнат, не внутри диапазона.
- `sameSeedWindow(0, 299_999)` true, `300_000` false.
- множитель raid hp 3, damage 2, loot 3.

## Definition of done

20 разных сидов small не бросают и все связные.
