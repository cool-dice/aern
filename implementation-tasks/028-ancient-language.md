## Цель

Для игрока собрать подстановочный шифр сервера, для бота — отдать тот же фрагмент структурированным JSON.

## Контекст

Артефакт 3, раздел Древнего языка. Шифр уникален для сервера. Люди видят символы и ключи. Боты не решают шифр и сразу получают поля lore, coordinates, recipe, password, confidence.

Решение о виде шифра: Цезарь не используем, только подстановка. Алфавит открытого текста — 33 буквы русского нижнего регистра без ё, плюс пробел не шифруется. Символы шифра — 33 печатных знака из фиксированной строки `CIPHER_GLYPHS` в файле (ASCII `!#$%&()*+,-./0123456789:;<=>?@[]^_` плюс сколько нужно до 33, зафиксировать константой ровно 33 символа без пробела).

Ключ сервера — перестановка, порождённая `mulberry32(hashSeed(serverSecret))` алгоритмом Фишера–Йетса. Один secret → один и тот же ключ.

Фрагмент: `{id, plaintext, x, y, recipeId, password}`. Игроку `renderFragment` возвращает ciphertext и список ключей-пар, которые персонаж уже нашёл (`knownLetters`). Боту `renderBotRecord` возвращает объект с confidence 0.9 и координатами, без шифра.

Расшифровка попытки игрока: если присланная подстановка совпала с серверной на всех известных и на попытке полного текста, вернуть plaintext. Частичная проверка не раскрывает неизвестные буквы. Функция `decode(ciphertext, permutation)` применяет обратную подстановку.

УПЯ древнего не заменяет шифр. Даже при УПЯ 100 игрок видит ciphertext, пока не расшифровал фрагмент в журнале. После успешной сдачи фрагмент помечается `solved: true` и показывается plaintext. Это личный слой.

Награда опыта за первый фрагмент +100 — снаружи, задача прогрессии. Здесь только флаг первого решения.

## Решение противоречий

Боты не проходят мини-игру частотного анализа. Секрет сервера не хардкодить: аргумент `serverSecret`. В тестах секрет `test-secret`.

## Интерфейсы

```ts
export const PLAIN_ALPHABET: string;
export const CIPHER_GLYPHS: string;
export function buildPermutation(serverSecret: string): string; // 33 глифа в порядке букв алфавита
export function encodeAncient(plain: string, permutation: string): string;
export function decodeAncient(cipher: string, permutation: string): string;
export function botRecord(fragment: {
  id: string; lore: string; x: number; y: number; recipeId: string; password: string;
}): { event: 'ancient_record'; location: string; content: { lore: string; coordinates: { x: number; y: number }; recipe: string; password: string }; confidence: 0.9 };
```

Неизвестные символы plaintext (латиница, цифры) копируются как есть и не считаются ошибкой.

## Алгоритм

- Фишер–Йетс на копии массива глифов.
- Пробелы сохраняются.
- Буква `ё` заменяется на `е` до шифрования.
- Верхний регистр приводится к нижнему.

## Тесты

- один secret → одна перестановка. Другой secret с высокой вероятностью другой: взять `other`. Если вдруг совпали, выбрать секрет `other-2` ожиданием неравенства — лучше проверить два фиксированных секрета и захардкодить ожидаемую первую глифу, вычислив её при написании теста один раз через саму функцию: тест «стабильность», не конкретный символ, плюс тест что encode/decode круглые: `decode(encode(s)) === s` для `привет мир`.
- пробел остаётся пробелом.
- botRecord содержит password и confidence 0.9 и не содержит глифов шифра.
- перестановка длиной 33 и без повторов.
