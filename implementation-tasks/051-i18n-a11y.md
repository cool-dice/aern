## Цель

Выбрать строку ru или en, плюрализовать по-русски и отдать настройки доступности.

## Контекст

Артефакты 30 и 33. Старт: ru и en. zh-CN не подключать. Ключи `ui.menu.play` и т.д. Плюрал ru: one, few, many, other. Правило: n % 10 == 1 и n % 100 != 11 → one; n % 10 in 2..4 и n % 100 not in 12..14 → few; иначе many. other не используется для ru, но ключ может быть.

Формат `{name}` заменяется. Нет вложенных выражений ICU. Отсутствующий ключ возвращает сам ключ.

Настройки: fontScale 1 | 1.25 | 1.5, contrast `normal` | `high`, subtitles boolean, reduceMotion boolean, colorblind режим из задачи 049 (дублировать тип строкой, не импортировать ui, чтобы не связать папки: определить union здесь и в 049 одинаково).

Прототипные строки меню: Играть, Настройки, Выход / Play, Settings, Exit. Имена рас Люди/Demons: «Люди» и «Humans», «Демоны» и «Demons».

## Решение противоречий

Английский обязателен в прототипе, хотя артефакт 33 зовёт его пост-релизом.

Плюс использовать JSON локалей content не обязательно: клиентские строки лежат в ts-словарях, чтобы не тянуть ФС. Ключи предметов можно не дублировать все: функция принимает словарь аргументом, дефолт — меню и расы.

## Интерфейсы

```ts
export function t(locale: 'ru' | 'en', key: string, vars?: Record<string, string | number>): string;
export function pluralRu(n: number, forms: { one: string; few: string; many: string }): string;
export function normalizeSettings(input: Partial<Settings>): Settings;
```

## Алгоритм

- plural подставляет `{count}`.
- 1, 21, 31 → one; 11, 111 → many; 2, 3, 4, 22 → few; 5, 12 → many.

## Тесты

- t ru `ui.menu.play` → «Играть». en → «Play».
- неизвестный ключ возвращается как ключ.
- `{name}` подставляется.
- плюрал 1/2/5/11/21.
- fontScale 2 нормализуется к 1 (откат к умолчанию, не ошибка — отличие от UI-модели; зафиксировать: settings мягко откатываются, модель крафта строгая. Здесь мягко).
- locale `zh` в normalize → `ru`.
