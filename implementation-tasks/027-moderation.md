## Цель

Автопроверка чата и лестница наказаний без панели администратора.

## Контекст

Артефакты 16 и 32. Мьют 1–24 часа, бан чата 7 суток, временный бан аккаунта 1–30 суток, повтор → постоянный бан. Роли: игрок, модератор, администратор. Гильдия не банит.

Числа автомодерации в GDD не заданы. Зафиксировать:

- спам: 5 одинаковых сообщений за 10 секунд или 8 любых за 10 секунд → мьют 1 час.
- капс: длина ≥ 8 и доля букв в верхнем регистре > 0.7 среди букв (не цифр) → мьют 1 час. Строка без букв не капс.
- чёрный список: точное совпадение слова в нижнем регистре по пробелам → мьют 1 час.
- 3 автомута за 24 часа → бан чата 7 суток.
- 3 флага читов (`cheatStrikes`) за 24 часа → бан аккаунта 7 суток. Флаг чита ставит античит, не этот модуль: функция только принимает счётчик.
- второе окно постоянных нарушений (`permanentIfRepeat: true`, которое сервис ставит если уже был бан) → `permanent`.

Ложный репорт: отдельная функция, мьют 24 часа.

Сообщение длиннее 500 уже отвергает чат. Здесь проверяется содержание принятого текста.

## Решение противоречий

Серверная модерация, не гильдейская. Постоянный бан может выдать только роль `admin` в функции `reviewAppeal` не требуется: эскалация автоматическая только для повторного бана, помеченного сервисом.

## Интерфейсы

```ts
export type Sanction = 'none' | 'mute_1h' | 'mute_24h' | 'chat_ban_7d' | 'account_ban_7d' | 'permanent';

export function classifyMessage(input: {
  text: string;
  recentTexts: string[];
  recentMs: number[];
  nowMs: number;
  blacklist: string[];
  automutesIn24h: number;
}): Sanction;

export function sanctionForCheatStrikes(strikesIn24h: number, repeatOffender: boolean): Sanction;
export const MUTE_1H_MS = 3_600_000;
export const CHAT_BAN_MS = 7 * 86_400_000;
```

`recentTexts` — предыдущие сообщения того же автора в окне, без текущего. Функция сама решает, попадает ли текущее в спам вместе с ними. `recentMs` параллельный массив времён. Сообщения старше 10 секунд не считаются.

## Алгоритм

- Окно спама 10_000 мс.
- Одинаковость — точное равенство строки после trim, регистр важен для спама, чтобы не смешивать с капсом.
- Если сработали и капс, и спам — вернуть один `mute_1h`, не два.
- Если `automutesIn24h >= 2` и текущее сообщение снова наказуемо, вернуть `chat_ban_7d` вместо mute (это будет третьим).
- Чёрный список пустой по умолчанию в тестах, кроме одного слова `slug`.

## Тесты

- четыре одинаковых и пятое → mute. Три одинаковых → none.
- 7 разных за 10 секунд и восьмое → mute. Девятое через 11 секунд при пустом окне → none.
- `AAAAAAAA` → mute. `AAAAAAA` длина 7 → none. `AaAaAaAa` доля 0.5 → none.
- слово из blacklist → mute.
- automutesIn24h 2 и капс → chat_ban_7d.
- strikes 3 → account ban. strikes 2 → none. repeat → permanent.
- ложный репорт отдельной функцией `falseReportSanction()` → mute_24h.
