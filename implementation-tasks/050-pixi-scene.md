## Цель

Построить описание кадра псевдо-3D: пол, спрайты сущностей в видимом радиусе, без обязательного WebGL в тестах.

## Контекст

Артефакты 24 и 27. Вид от первого лица, спрайты. Render 60 FPS — цель рантайма, не юнит-теста. В тесте чистая функция `buildFrame` возвращает список спрайтов, отсортированных по дистанции от камеры (дальние сначала).

Камера: клетка игрока и facing. Видимость — квадрат Чебышёва радиуса `vision` (из статов, аргумент). Сущность дальше не попадает в кадр.

Проекция: экранная x = (dx - dy) * 32, y = (dx + dy) * 16 - z. z пола 0, спрайта 16. Это изометрия как замена «псевдо-3D» без настоящего рейкаста. Решение старта: изометрическая проекция клеток, не raycasting. Документ просит псевдо-3D спрайты; изометрия достаточна для прототипа и тестируется без GPU.

Стены: клетка `blocked` рисуется тайлом `wall`, пол — `floor`.

`createApplication` в `pixi-app.ts` импортирует pixi и не вызывается тестом.

## Решение противоречий

Нет raycast-движка в зависимостях. Изометрия — зафиксированное упрощение, чтобы кадр был детерминирован.

## Интерфейсы

```ts
export interface SpriteDesc { id: string; image: string; x: number; y: number; zIndex: number }
export function buildFrame(input: {
  origin: Cell;
  facing: Dir;
  vision: number;
  blocked: Cell[];
  entities: { id: string; cell: Cell; image: string }[];
}): SpriteDesc[];
```

## Алгоритм

- zIndex = дистанция Чебышёва, меньшая дистанция рисуется позже (большее zIndex у ближних).
- Сущность на клетке игрока не дублирует игрока: id `self` всегда в кадре в центре проекции 0,0 относительно... самопроекция self: dx 0 dy 0 → x 0 y -16.
- Facing не крутит мир в этой версии: камера смотрит на +x мира как восток. Поворот меняет только последующие шаги, не проекцию. Записать это ограничение в комментарии. Поворот спрайтов — image id с суффиксом facing, аргумент entity.image уже выбран вызывающим.

## Тесты

- сущность на расстоянии vision+1 отсутствует.
- сущность на расстоянии vision есть.
- порядок: дальняя стена имеет меньший zIndex, чем ближняя.
- self в кадре один.
- одна и та же сцена → глубоко равные массивы.
